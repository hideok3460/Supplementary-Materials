# Supplementary Material S1

This directory contains Supplementary Material S1 for the manuscript:

**Exact Logical-Channel Equivalence and Code-Space-Leakage-Aware Tomography of a Five-Qubit Coherent EPR-State Transfer Network**

## Files

- `Supplementary_Appendix_Br2.tex` — LaTeX source of Supplementary Material S1.
- `SSupplementary_Appendix_Br2.pdf` — compiled PDF for submission as a separate supplementary file.

S1 contains only the extended controlled-X notation and tensor-embedding derivation. The same-backend hardware acquisition and CP-TNI reconstruction are documented in Supplementary File S2, `verification_canonical_noncanonical_CP_TNI.ipynb`. The reproducibility exporter and complete raw-data provenance archive are provided as Supplementary Files S3 and S4: `verification_canonical_noncanonical_CP_TNI_reproducibility_export.ipynb` and `Exact_Channel_Equivalence_hardware_reproducibility_archive.zip`. These artifacts are also identified as publicly available through the companion repository cited as `okazaki2` in the main manuscript.
