# Supplementary Material S1

This directory contains Supplementary Material S1 for the manuscript:

**Exact Channel Equivalence and Leakage-Aware Same-Backend Tomography for a Five-Qubit Coherent EPR-State Transfer Network with a GHZ-Type Resource Family**

## Files

- `Supplementary_Appendix_B.tex` — LaTeX source of Supplementary Material S1.
- `Supplementary_Appendix_B.pdf` — compiled PDF for submission as a separate supplementary file.

S1 contains only the extended controlled-X notation and tensor-embedding derivation. The same-backend hardware acquisition and CP-TNI reconstruction are documented in the separate executed notebook `verification_canonical_noncanonical_CP_TNI.ipynb` and its machine-readable summaries.
